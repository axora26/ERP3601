# Integrations

**Status: NOT STARTED.** No external integrations (AI gateway, Smart
Building protocols, payment/banking, e-signature, etc.) exist in Wave 1.

Per mission Section 33, when an AI gateway is eventually added: no
provider is ever considered available without a live test, no key is
committed, data classification (`PUBLIC`/`INTERNAL`/`CONFIDENTIAL`/`RESTRICTED`)
gates what can leave the system, and the policy is fail-closed by default.
None of that exists to configure yet — this file will be filled in when
the first integration is actually built (Wave 12 at the earliest per
`docs/IMPLEMENTATION_ROADMAP.md`), not before.
